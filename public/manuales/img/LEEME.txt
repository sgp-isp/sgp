 CAPTURAS DE PANTALLA PARA LOS MANUALES DE USUARIO (manuales/*.html)
==========================================================================

¿CÓMO FUNCIONA?
---------------
Cada manual (manual_pasante.html, manual_tutor.html, manual_administrador.html,
manual_superadministrador.html) ahora intenta cargar automáticamente una
imagen desde esta carpeta "img/" para cada captura de pantalla requerida.

- Si el archivo EXISTE -> se muestra la imagen a ancho completo.
- Si el archivo NO EXISTE (404) -> se muestra el recuadro punteado azul
  "[ Captura de pantalla requerida ]" como hasta ahora.

NO hay que tocar el código HTML para nada de esto. Solo hay que:
  1. Tomar la captura de pantalla indicada.
  2. Guardarla en formato PNG (o JPG donde se indique) con el NOMBRE EXACTO
     de la lista de abajo (en minúsculas, con guiones, sin espacios).
  3. Copiar el archivo a esta carpeta: sgp/public/manuales/img/
  4. Recargar el manual .html en el navegador (Ctrl+F5) para verla.

Varias imágenes se REUTILIZAN en más de un manual (por ejemplo, la pantalla
de inicio de sesión es la misma para los 4 roles). Basta con guardarla UNA
sola vez con el nombre indicado y aparecerá en todos los manuales que la usan.

==========================================================================
 GUÍA RÁPIDA: PASOS GENERALES PARA TOMAR CADA CAPTURA
==========================================================================
1. Abrir http://localhost/proyecto_sgp/sgp/public + la ruta indicada
   (iniciar sesión con el rol correspondiente cuando se requiera).
2. Ajustar el tamaño de la ventana (o F12 -> ícono "Responsive" en
   DevTools) al ancho/alto indicado: 1280x800 o 1440x900 px.
3. Tomar la captura: Win+Shift+S (recorte) o una extensión de
   "captura de página completa".
4. Guardar como PNG con el NOMBRE EXACTO de la lista (minúsculas,
   con guiones).
5. Copiar el archivo a sgp/public/manuales/img/
6. Recargar el manual .html (Ctrl+F5) para confirmar que se vea bien.
